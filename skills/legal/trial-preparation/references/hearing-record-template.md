## 使用说明

1. **生成时**：优先写入案件目录的 `分析材料/`；文件名与主标题都用简称。
2. **庭前**：把发问、辩论、争议焦点按"拟"的口径填好，作为准备稿。
3. **庭上**：在 WPS 思维导图里对着对应节点补记实际发生的陈述、法庭归纳与当庭决定。
4. **庭后**：核对"需补充事项"表，确认提交方、材料名称、期限。

## 常见错误

| 错误 | 后果 |
|------|------|
| 子标题加了 `1.` `2.` 阿拉伯序号 | 导入思维导图后层级混乱，庭上不好插节点 |
| 缺某个一级节点 | 庭上补记时找不到位置 |
| 把拟发问写成"审判长问……" | 混淆准备稿与庭审事实 |
| 证人、时间、地点靠猜填上 | 与卷宗不符，庭上被指出很被动 |
| 证据清单里多出卷内没有的证据 | 举证被质疑，影响可信度 |
