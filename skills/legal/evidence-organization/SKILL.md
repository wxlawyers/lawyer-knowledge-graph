# 证据组织与四性验证技能

面向中国诉讼律师的证据管理框架，提供从证据收集到质证准备的全流程支持。

## 适用场景

- 新案证据收集与整理
- 证据四性验证（真实性、合法性、关联性、充分性）
- 证据链构建与补强
- 证据清单编制
- 质证准备与对抗

## 执行步骤

### 步骤一：证据收集

#### 证据类型
1. **书证**
   - 合同/协议
   - 付款凭证
   - 发票/收据
   - 往来函件
   - 公司文件（章程、决议、会议纪要）

2. **物证**
   - 产品实物
   - 现场物品
   - 痕迹物证

3. **视听资料**
   - 录音
   - 录像
   - 监控视频

4. **电子数据**
   - 微信聊天记录
   - 电子邮件
   - 短信
   - 电子合同
   - 区块链存证

5. **证人证言**
   - 当事人陈述
   - 证人证言
   - 专家证人

6. **鉴定意见**
   - 笔迹鉴定
   - 价格鉴定
   - 伤残鉴定
   - 工程鉴定

7. **勘验笔录**
   - 现场勘验
   - 物证勘验

#### 收集方法
1. **当事人提供**
   - 指导当事人收集
   - 告知举证责任
   - 提供证据清单

2. **法院调查取证**
   - 申请法院调查令
   - 申请法院调取证据
   - 申请法院委托鉴定

3. **公证保全**
   - 电子数据公证
   - 现场公证
   - 送达公证

4. **区块链存证**
   - 电子数据上链
   - 时间戳固定
   - 哈希值验证

### 步骤二：证据整理

#### 整理原则
1. **按时间顺序**
   - 按事件发生时间排列
   - 形成时间线
   - 便于还原事实

2. **按证据类型**
   - 书证、物证、视听资料等
   - 便于分类管理
   - 便于质证准备

3. **按证明目的**
   - 按争议焦点分组
   - 每组证据证明同一事实
   - 形成证据链

#### 整理方法
1. **编号**
   - 连续编号，不得跳号
   - 原件与复制件对应
   - 便于查阅引用

2. **编排**
   - 制作证据目录
   - 标注页码
   - 装订成册

3. **标注**
   - 标注证据来源
   - 标注证明目的
   - 标注四性验证结果

#### 双视图输出（2026-10-02 新增）

同一批证据要出**两张表**，用同一套编号，供不同场景调用：

| 视图 | 排序依据 | 用在什么时候 |
|------|----------|--------------|
| **按来源视图** | 证据来源（当事人提供 / 第三方出具 / 法院调取 / 对方提交） | 整理、核对、装订、判断取证合法性 |
| **按证明目的视图** | 待证事实 / 争议焦点 | 举证、质证、写代理词、搭证据链 |

两张表的证据编号必须一致，任何一张表里都不能出现另一张表没有的证据。

#### 证据卡片（结构化底稿）

逐份材料提取一张证据卡片，作为两张视图和后续质证的共同数据源：

| 字段 | 说明 |
|------|------|
| 编号 | 与证据清单一致（如 证 01） |
| 来源文件 | 原始材料文件名 / 卷宗页码 |
| 原文摘要 | 关键内容摘录，**照录原文**，不改写 |
| 发言者 | 己方 / 对方 / 第三方 / 不确定（聊天记录类必填，见下） |
| 证明目的 | 承认欠款 / 确认事实 / 时间节点 / 金额记录 / 身份关系 / 合同约定 / 其他 |
| 时间 | 相关日期 |
| 金额 | 相关金额 |
| 置信度 | 高 / 中 / 低；**低置信度必须标"待确认"** |

**聊天记录类证据的发言人标注（强制）**：微信、短信、QQ、邮件往来等，每条卡片必须标注发言者身份——己方、对方、第三方（群聊中的其他人）、不确定。**无法判断的一律写"不确定"，不得推测**。这是聊天记录被对方质疑"截取片段、断章取义"时最容易被攻击的地方。

**置信度怎么定**：

- 高：原文明确、指向清楚、无歧义；
- 中：需要结合其他证据才能确定指向；
- 低：内容模糊、缺少上下文、或需鉴定（如未鉴定的笔迹、截图）。

#### 证据关系推断（按类别检查）

不同法律关系需要凑齐的证据组合不同，缺口要在这一步标出来：

| 法律关系 | 常规证据组合 | 常见缺口 |
|----------|--------------|----------|
| 借贷 | 借款合意 + 款项交付凭证 | 只有借条无转账记录（或只有转账无合意） |
| 买卖 | 合同/订单 + 交付凭证 + 对账/催款 | 交付无签收、对账无确认 |
| 服务/承揽 | 合同 + 履行过程记录 + 验收/结算 | 无过程记录，工作量无法证明 |
| 劳动 | 劳动关系证明 + 工资记录 + 解除通知 | 无书面劳动合同、工资走现金 |
| 侵权 | 加害行为 + 损害后果 + 因果关系 | 因果关系缺鉴定或专业意见 |

### 步骤三：四性验证

### 步骤三：四性验证

#### 1. 真实性验证

**书证**
- 是否原件？复印件是否有原件核对？
- 是否有涂改、伪造痕迹？
- 签名/盖章是否真实？
- 形成时间是否明确？

**电子数据**
- 原始存储介质是否保存？
- 是否有篡改可能？
- 公证保全或区块链存证？
- 提取过程是否有见证人？

**证人证言**
- 证人与当事人关系？
- 证人是否具备作证能力？
- 证言是否前后一致？
- 是否有其他证据佐证？

#### 2. 合法性验证

**取证方式**
- 是否侵犯他人合法权益？
- 是否违反法律禁止性规定？
- 是否严重违背公序良俗？

**常见非法证据**
- 偷录偷拍（侵犯隐私权）
- 非法侵入他人住宅获取
- 通过暴力、威胁手段获取
- 严重违反法定程序获取

#### 3. 关联性验证

**判断标准**
- 证据与待证事实是否有逻辑联系？
- 证据能否证明或反驳某项事实？
- 证据与其他证据是否矛盾？

**常见无关联证据**
- 与案件无关的背景信息
- 当事人的品格证据（一般情况）
- 其他案件的证据

#### 4. 充分性验证

**证据链完整性**
- 是否形成完整证据链？
- 是否有缺失环节？
- 能否排除合理怀疑？

**证明标准**
- 民事：高度盖然性（优势证据）
- 刑事：排除合理怀疑
- 行政：清楚且有说服力

### 步骤四：证据链构建

#### 证据链要素
1. **合同签订环节**
   - 合同原件
   - 签约过程证据
   - 合同变更证据

2. **合同履行环节**
   - 履行行为证据
   - 履行时间证据
   - 履行方式证据

3. **违约事实环节**
   - 违约行为证据
   - 违约时间证据
   - 违约后果证据

4. **损失计算环节**
   - 损失范围证据
   - 损失金额证据
   - 因果关系证据

#### 构建方法
1. **确定待证事实**
   - 列出需要证明的事实
   - 确定举证责任分配
   - 确定证明标准

2. **匹配证据**
   - 每个待证事实对应证据
   - 证据之间相互印证
   - 形成完整证据链

3. **补强证据**
   - 识别缺失环节
   - 补充收集证据
   - 申请法院调取

### 步骤五：证据清单编制

#### 清单内容
| 序号 | 证据名称 | 证据类型 | 证据来源 | 证明目的 | 页码 | 备注 |
|------|----------|----------|----------|----------|------|------|
| 1 | | | | | | |

#### 编制要求
1. **编号连续**：不得跳号
2. **页码准确**：便于查阅
3. **证明目的明确**：每个证据的证明目的
4. **四性验证**：逐项验证并标注
5. **双视图齐备**：同时出「按来源」与「按证明目的」两张表，编号一致
6. **低置信度标注**：置信度为低的证据必须在备注列标"待确认"

### 步骤六：质证准备

#### 对方证据质证
1. **真实性异议**
   - 是否原件？
   - 有无篡改？
   - 签名是否真实？

2. **合法性异议**
   - 取证方式是否合法？
   - 是否侵犯他人权益？
   - 是否违反法定程序？

3. **关联性异议**
   - 与本案是否相关？
   - 能否证明对方主张？
   - 是否有其他证据佐证？

4. **证明目的异议**
   - 能否证明对方主张？
   - 是否有其他解释？
   - 是否与其他证据矛盾？

#### 我方证据补强
1. **补充证据**
   - 是否有其他证据佐证？
   - 是否需要申请鉴定？
   - 是否需要申请法院调查取证？

2. **证据说明**
   - 证据来源说明
   - 证据形成过程
   - 证据证明力说明

## 质量标准

### 四性验证
1. **真实性** — 证据是否真实，有无伪造、篡改
2. **合法性** — 取证方式是否合法
3. **关联性** — 证据与待证事实是否相关
4. **充分性** — 证据是否形成完整证据链

### 证据链完整性
- 是否覆盖所有待证事实
- 证据之间是否相互印证
- 是否有缺失环节

## 安全要求

- 当事人敏感信息脱敏处理
- 证据原件妥善保管
- 电子数据备份保存

## 事实核验原则

- 任何法条、案例、案号、金额与事实结论，必须可回源到真实材料或实际检索结果；禁止编造或凭记忆补全。
- 来源缺失或无法核验时，输出 `[待补: ...]` 占位符，并说明缺什么、应去哪里查找。
- 正式交付前由使用者复核全部引用与数字；AI 不得把未核验内容表述为已核验依据。
