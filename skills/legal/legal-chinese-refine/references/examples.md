# 改写前后对照

> 每条左侧是常见写法，右侧是处理后的写法。**注意**：右列只改表达，事实、金额、立场、不确定性都没有动。

## 一、事实与评价混层

| 原文 | 改写 |
|------|------|
| 被告恶意拖欠货款，毫无诚信 | 截至 2024 年 3 月 1 日，被告尚有货款 100 万元未支付 |
| 原告提供的证据根本站不住脚 | 原告提交的证据 XXX 不能证明其主张的 YYY，理由如下 |
| 众所周知，该行业惯例就是先款后货 | 依据双方合同第 X 条及行业惯例，付款义务先于交付义务 |

## 二、主张被升级成认定

| 原文 | 改写 |
|------|------|
| 证据充分证明被告构成违约 | 我方认为，现有证据足以支持被告构成违约的主张 |
| 可以确认损失为 50 万元 | 我方主张的损失金额为 50 万元，依据为 XXX |
| 被告已经承认欠款 | 被告在与原告的通话中表示"这笔钱确实还欠着"（证据 3） |

## 三、不确定性被抹掉

| 原文 | 改写 |
|------|------|
| 该行为构成欺诈 | 该行为**可能**构成欺诈（需结合 XX 事实进一步判断） |
| 合同无效 | 合同**存在**被认定无效的风险 |
| 被告应当承担全部责任，没有例外 | 被告应当承担赔偿责任；**除**XX 情形外，该责任不因 YY 而免除 |

## 四、笼统否认

| 原文 | 改写 |
|------|------|
| 对原告的全部证据均不予认可 | 对证据 1、2 的真实性不持异议；对证据 3 的真实性不予认可，对证据 4 的关联性不予认可，理由如下 |
| 被告的抗辩毫无依据 | 被告关于 XX 的抗辩不能成立，理由一……理由二…… |

## 五、术语误用（只标注，不擅改）

| 原文 | 处理 |
|------|------|
| "原告主张撤销合同" （上下文实际是解除） | 标注：`需核验：此处"撤销"与"解除"的法律效果不同，请确认是否应改为"解除"` |
| "被告支付了定金 5 万元" （合同写"订金"） | 标注：`需核验：合同原文为"订金"，本稿写为"定金"，两者法律效果不同` |
| "应当"与"可以"混用 | 逐处列出，提示确认哪一处的表述反映真实约定 |

## 六、冗余与口语

| 原文 | 改写 |
|------|------|
| 关于这个事情呢，我方是这样认为的 | 我方认为 |
| 在此，我方想特别强调一下 | 我方特别指出 |
| 综上所述，基于以上所有的这些理由 | 综上 |
| 由于因为……的原因导致 | 因…… |

## 七、通俗转译（给当事人）

| 原文 | 改写 |
|------|------|
| 被告的行为构成根本违约，原告依法享有法定解除权 | 对方的行为已经严重违反合同约定，这种情况下你有权解除合同 |
| 本案适用举证责任倒置 | 这种案子，法律规定由对方来证明自己没有过错，而不是由你来证明对方有过错 |
| 该主张存在诉讼时效经过的抗辩风险 | 存在一个风险：如果拖得太久，对方可能主张"已经过了起诉期限"，因此建议尽快行动 |

**注意**：转译后仍要保留结论强度和例外，不能为了好懂把"通常"说成"一定"。

## 八、文书链不一致

多份文书核对时最常发现的问题（只报告，不擅自统一）：

| 类别 | 例子 |
|------|------|
| 主体名称 | 起诉状用全称、代理词用简称，且简称指代不明 |
| 金额 | 起诉状 100 万，代理词附录 98 万，无差异说明 |
| 日期 | 两处对"首次催告日"记载不同 |
| 证据编号 | 代理词引用的"证据 5"在证据目录里是另一份材料 |
| 术语 | 一处写"解除"，一处写"撤销" |
| 立场 | 一稿主张继续履行，另一稿主张解除，未说明关系 |
