# 保全与强制执行技能

面向中国民商事诉讼律师的保全与执行实务框架，覆盖从保全申请到执行异议处理的全流程。

## 适用场景

- 诉前财产保全与诉中财产保全
- 行为保全（责令停止侵害、排除妨碍等）
- 保全担保、保全错误赔偿风险控制
- 判决/调解书生效后的强制执行申请
- 执行异议（当事人异议、案外人异议）与执行和解

## 执行步骤

### 步骤一：保全方案设计

1. 评估保全必要性：是否存在转移、隐匿、变卖财产的风险
2. 确定保全对象：银行账户、不动产、车辆、股权、应收账款、知识产权等
3. 选择保全时机：诉前保全（情况紧急，需在保全后三十日内起诉或申请仲裁）或诉中保全
4. 测算保全范围：以请求范围为限或与本案有关，避免超标的保全

### 步骤二：保全申请与担保

1. 提交保全申请书（当事人信息、保全请求、事实理由、担保情况、财产线索）
2. 提供财产线索（账户信息、房产证号、车辆信息等）
3. 评估担保方式：现金、保函、抵押、保险公司保全责任险
4. 诉前保全原则上须提供担保；诉中保全由法院视情况责令担保

### 步骤三：保全执行与后续

1. 跟踪保全裁定与保全措施实施
2. 保全错误风险提示：申请保全错误造成损失的，申请人应赔偿（《民事诉讼法》相关规定）
3. 保全解除情形：保全期限届满、被保全财产置换、案件审结等
4. 续封续冻：注意保全期限（银行存款冻结、动产查封、不动产查封的期限），到期前及时续保

### 步骤四：强制执行申请

1. 确认执行依据生效（判决书、调解书、仲裁裁决、公证债权文书等）
2. 检查申请执行时效：申请执行的期间为二年，中止、中断适用诉讼时效有关规定
3. 提交执行申请书与执行依据、身份证明、财产线索
4. 向第一审人民法院或者被执行的财产所在地人民法院申请

### 步骤五：执行程序跟进与异议处理

1. 查询执行进展（网络查控、财产处置、拍卖变卖）
2. 执行和解与执行担保的运用
3. 执行异议：当事人、利害关系人认为执行行为违反法律规定的，可提出书面异议；案外人对执行标的有异议的，依程序提出
4. 执行不能时的终本程序与恢复执行路径

## 注意事项

- 保全与执行均为程序性权利，先核对期限（保全后起诉期限、续保期限、执行期间）避免权利丧失
- 保全线索越具体成功率越高，引导客户提供完整财产信息
- 涉及执行异议之诉等复杂程序时，先判断异议类型再选择救济路径
- 失信惩戒、限制消费等配套措施可作为执行谈判筹码
