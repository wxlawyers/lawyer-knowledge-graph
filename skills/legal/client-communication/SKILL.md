# 当事人沟通技能

面向中国诉讼律师的当事人沟通框架，提供从案情表达到预期管理的全流程支持。

## 适用场景

- 案情通俗化表达
- 风险坦诚告知
- 预期管理
- 沟通技巧
- 对外交付物制作（服务计划书、工作通报、决策辅助清单、庭审简报）

## 对内与对外：一条不能越过的线（2026-10-02 新增）

律师的产出分两类，混用会出事：

| | 对内产出 | 对外产出 |
|---|---|---|
| 例子 | 案件分析、代理思路、质证提纲、风险评估、策略预案 | 服务计划书、工作通报、决策辅助清单、庭审简报 |
| 读者 | 自己、团队 | 当事人 |
| 要求 | 完整、坦率、可以写难点和不确定 | **脱敏**：交代进展与依据，不暴露底牌 |

**脱敏红线（违反即作废）**

1. 不写诉讼/谈判策略底牌（打算怎么打、先打哪一点、准备让步到哪）；
2. 不写对法官、对方当事人及其代理人的主观评价；
3. 不写尚未核实的事实，也不把推测写成结论；
4. 不写内部风险评估的原始分级与用词（可转译为通俗表达）；
5. 涉及当事人隐私、商业秘密的内容，按最小必要原则披露。

## 四类对外交付物

完整模板见 `references/client-facing-deliverables.md`。

### 1. 服务计划书（阶段启动时）

告诉当事人：这一阶段我们做什么、分几步、需要他配合什么、大概多久。作用是**管理预期**，让当事人知道钱花在哪。

### 2. 工作通报（有实质进展时）

说清三件事：**做了什么 → 结果是什么 → 下一步做什么、需要他做什么**。不要只写"已在跟进"。

### 3. 决策辅助清单（需要当事人拿主意时）

把选项、利弊、成本、时间摆成表格，**决定权明确交还当事人**，律师只做分析不代替决定。适用于和解、是否上诉、是否鉴定、是否认罪认罚等。

### 4. 庭审简报（开庭前后）

开庭前告知准备情况与注意事项；开庭后简要说明当天发生了什么、法庭归纳的争议焦点、下一步安排。**只写公开发生的庭审情况，不写内部策略。**

### 阶段里程碑对照

| 阶段 | 常规交付物 |
|------|------------|
| 接案后 | 服务计划书 |
| 立案 / 提交材料后 | 工作通报 |
| 开庭前 | 庭审简报（准备情况）+ 需当事人配合事项 |
| 庭审后 | 庭审简报（庭审情况） |
| 出现和解、上诉等岔路口 | 决策辅助清单 |
| 结案 | 结案报告（结果 + 费用结算 + 后续提示） |

## 执行步骤

### 步骤一：案情通俗化表达

#### 表达原则
1. **简洁明了**
   - 语言简洁
   - 表达清晰
   - 重点突出

2. **通俗易懂**
   - 避免法律术语
   - 使用日常用语
   - 举例说明

3. **客观真实**
   - 客观陈述
   - 不夸大
   - 不缩小

#### 表达技巧
1. **类比说明**
   - 用生活案例类比
   - 用常见事物类比
   - 用简单逻辑类比

2. **图表说明**
   - 时间线图表
   - 流程图
   - 关系图

3. **案例说明**
   - 类似案例
   - 成功案例
   - 失败案例

#### 案情表达模板
```
案情说明

一、案件基本情况
（用通俗语言描述案件事实）

二、法律关系
（用通俗语言解释法律关系）

三、争议焦点
（用通俗语言说明争议焦点）

四、诉讼请求
（用通俗语言说明诉讼请求）

五、法律依据
（用通俗语言说明法律依据）
```

### 步骤二：风险坦诚告知

#### 告知原则
1. **全面告知**
   - 告知所有风险
   - 不隐瞒风险
   - 不淡化风险

2. **客观告知**
   - 客观分析风险
   - 不夸大风险
   - 不缩小风险

3. **及时告知**
   - 及时告知风险
   - 不拖延告知
   - 不事后告知

#### 风险类型
1. **诉讼风险**
   - 败诉风险
   - 部分败诉风险
   - 执行风险

2. **程序风险**
   - 时效风险
   - 管辖风险
   - 证据风险

3. **成本风险**
   - 诉讼费风险
   - 律师费风险
   - 时间成本风险

```
2. 管辖风险：XXX

三、成本风险
1. 诉讼费风险：XXX
```

### 步骤三：预期管理

#### 管理原则
1. **现实预期**
   - 建立现实预期
   - 不建立过高预期
   - 不建立过低预期

2. **动态调整**
   - 根据案件进展调整
   - 根据证据变化调整
   - 根据法律变化调整

3. **及时沟通**
   - 及时沟通预期变化
   - 不拖延沟通
   - 不隐瞒变化

#### 预期管理技巧
1. **预期设定**
   - 设定合理预期
   - 设定最低预期
   - 设定最高预期

2. **预期调整**
   - 根据案件进展调整
   - 根据证据变化调整
   - 根据法律变化调整

3. **预期沟通**
   - 及时沟通预期变化
   - 解释变化原因
   - 提供应对方案

### 步骤四：沟通技巧

#### 倾听技巧
1. **认真倾听**
   - 全神贯注
   - 不打断对方
   - 不急于下结论

2. **理解意图**
   - 理解对方真实意图
   - 理解对方情感需求
   - 理解对方利益诉求

3. **反馈确认**
   - 反馈理解内容
   - 确认理解是否正确
   - 避免误解

#### 表达技巧
1. **清晰表达**
   - 语言简洁
   - 表达清晰
   - 重点突出

2. **共情表达**
   - 理解对方感受
   - 表达理解
   - 建立信任

3. **专业表达**
   - 专业分析
   - 专业建议
   - 专业方案

#### 沟通话术模板
```

3. 反馈：XXX

三、表达话术
1. 案情说明：XXX

3. 预期管理：XXX
```

### 步骤五：沟通记录

#### 记录原则
1. **及时记录**
   - 及时记录沟通内容
   - 不拖延记录
   - 不遗漏重要内容

2. **准确记录**
   - 准确记录沟通内容
   - 不歪曲内容
   - 不添加内容

3. **完整记录**
   - 完整记录沟通内容
   - 不遗漏重要内容
   - 不省略重要内容

#### 记录内容
1. **沟通时间**
   - 沟通开始时间
   - 沟通结束时间
   - 沟通时长

2. **沟通方式**
   - 面谈
   - 电话
   - 微信
   - 邮件

3. **沟通内容**
   - 案件情况
   - 风险告知
   - 预期管理
   - 其他内容

4. **沟通结果**
   - 达成共识
   - 存在分歧
   - 后续安排

## 质量标准

### 沟通质量
1. **清晰性** — 是否清晰表达
2. **完整性** — 是否完整告知
3. **及时性** — 是否及时沟通
4. **有效性** — 是否有效沟通

### 风险告知质量
1. **全面性** — 是否全面告知
2. **客观性** — 是否客观告知
3. **及时性** — 是否及时告知
4. **可理解性** — 是否可理解
