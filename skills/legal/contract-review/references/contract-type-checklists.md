# 各类合同必备条款清单与高发风险点

> 用途：配合 `contract-review` 的「步骤四：缺失条款检查」。逐项核对，缺什么列什么；风险点用于提示重点审查位置。
> 说明：以下为**常见实务清单**，不是穷尽列举，也不能替代对具体交易结构和现行法的核对。

## 通用必备条款（所有合同都应有）

| 条款 | 缺失后果 |
|------|----------|
| 当事人完整信息与主体资格 | 主体不明，起诉时无法确定被告 |
| 标的与数量 | 合同标的不确定，可能不成立 |
| 价款或报酬及支付方式 | 无法主张付款请求 |
| 履行期限、地点、方式 | 违约时点无法认定 |
| 违约责任 | 只能主张一般损失赔偿，举证困难 |
| 合同解除条件与程序 | 无法及时止损退出 |
| 争议解决（诉讼或仲裁，二选一） | 管辖不明，可能被拖入异地诉讼 |
| 通知与送达（含送达地址确认） | 通知无法证明送达，解除/催告不生效 |
| 生效条件与签署 | 未约定生效条件时以签署为准，易生争议 |

## 一、买卖合同

**必备条款**：标的物具体描述（品名/规格/型号/数量）、质量标准与检验方式、包装与运输、交付时间地点、风险转移节点、验收程序与异议期、价款与发票、付款节点、所有权保留（如适用）、违约责任、解除条件、争议解决。

**高发风险点**

- 质量标准只写"符合国家标准"，未明确具体标准号与检验机构
- 验收条款缺失或只写"验收合格后付款"，未约定验收期限与逾期视为验收
- 风险转移与所有权转移混同，货损责任归属不明
- 质量异议期过短或未约定，买方丧失索赔权
- 违约金过低（如万分之零点五），无实际约束力

## 二、承揽 / 服务合同

**必备条款**：服务范围与交付成果、服务标准与验收标准、进度与里程碑、人员安排与替换限制、费用构成与调整机制、变更（change order）程序、成果与知识产权归属、保密、转委托限制、终止与退出、违约责任。

**高发风险点**

- "服务成果"描述模糊，验收争议无据可依
- 无变更程序，需求一改就扯费用
- 成果知识产权默认归受托方，委托方无法使用
- 无终止权或终止后费用结算规则缺失
- 服务水平（SLA）只写指标、不写未达标的补救与减免

## 三、租赁合同

**必备条款**：租赁物描述与权属、租期与起止日、租金及支付周期、押金及退还条件、用途限制、维修责任划分、水电物业等费用承担、转租与分租、提前解约条件与违约金、期满续租与优先承租、房屋交付与返还标准、登记备案。

**高发风险点**

- 押金退还条件不明或缺扣款依据
- 维修责任全部推给承租人，包括主体结构与自然损耗
- 出租方保留"随时收回"或大幅调租权
- 提前解约违约金畸高（押金全额没收 + 剩余租金）
- 未约定返还标准，退租时被主张大额恢复原状费用

## 四、借款合同

**必备条款**：借款金额与币种、借款用途、利率与计息方式、期限与还款方式、提前还款条件、逾期利息与罚息、担保安排、加速到期条款、争议解决、送达条款。

**高发风险点**

- 利率与逾期利率之和超过法定上限（民间借贷以合同成立时一年期 LPR 四倍为限，需按现行规则核对）
- 未约定逾期利息，出借人只能主张资金占用损失且举证困难
- 未约定加速到期，借款人一期违约后仍需逐期追索
- 未约定用途限制，借款人挪用时无法主张违约责任
- "砍头息"（预先扣除利息）导致本金被重新认定

## 五、保证合同

**必备条款**：被保证的主债权范围、保证方式（一般保证 / 连带责任保证）、保证期间、保证责任范围（本金/利息/违约金/实现债权费用）、最高额保证的额度与期间、主体资格与内部决议、追偿与反担保。

**高发风险点**

- 未明确保证方式，按一般保证处理，债权人须先诉债务人
- 保证期间未约定或约定不明，法律后果依规则确定，极易过期免责
- 保证人为公司但无股东会/董事会决议，效力存在争议
- 未覆盖实现债权的费用（律师费、保全费）
- 主合同变更未取得保证人书面同意，保证责任可能被免除

## 六、股权转让合同

**必备条款**：标的股权与比例、价款与支付节奏（含分期与尾款条件）、交割前提条件、工商变更与配合义务、过渡期限制（不得分红/处置资产）、陈述与保证、税务承担、未实缴出资的处理、违约责任、争议解决。

**高发风险点**

- 未约定交割前提，付款后无法完成工商变更
- 未处理原股东未实缴出资的补缴责任
- 债权债务披露不实但无陈述保证与赔偿条款
- 未约定其他股东放弃优先购买权的书面文件
- 税务承担约定与法定纳税义务冲突，实际无法执行

## 七、合伙协议

**必备条款**：出资方式与评估、利润分配与亏损分担、事务执行与决策机制（一般事项/重大事项）、入伙与退伙条件、财产份额转让限制、竞业禁止、财务与信息查阅、解散与清算、争议解决。

**高发风险点**

- 决策机制不清，重大事项僵局无解
- 退伙条件与份额结算方式缺失，退出即争议
- 未约定竞业禁止与保密
- 未约定财务公开与查阅权
- 债务承担方式与对外责任约定不一致

## 八、建设工程合同

**必备条款**：工程范围与工期、开工与竣工时间、合同价款与计价方式（固定总价/单价/成本加酬金）、进度款支付节点、变更与签证程序、材料与设备供应、质量与验收、保修期与保修金、安全责任、分包与转包限制、结算与审计、争议解决。

**高发风险点**

- 无书面变更与签证程序，增量工程款难以主张
- 结算以"审计结论"为准，但未约定审计期限与逾期后果
- 保修金比例与返还期限不明确
- 分包限制缺失，实际施工人主张权利时责任不清
- 工期延误的免责情形（不可抗力、发包人原因）未细化

## 九、保密协议 / NDA

**必备条款**：保密信息定义与例外、保密义务主体与范围、使用限制、期限与存续、返还或销毁、违约救济、是否含竞业或排他安排、争议解决。

**高发风险点**

- **以保密为名夹带其他条款**：竞业限制、排他、知识产权转让、不招揽、优先权、仲裁——出现即按高风险处理，逐条单独评估
- 保密信息定义过宽，日常经营信息也被纳入
- 期限为永久或过长，履行成本过高
- 未约定例外（已公开、独立开发、合法取得）
- 单向保密却要求双向义务
