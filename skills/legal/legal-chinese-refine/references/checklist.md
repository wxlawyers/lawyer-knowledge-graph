# 交付前自检清单

> 严格审校、结构诊断、文书链核对、长文本与高风险文本**必查**。

## 一、校异同（对照原材料）

- [ ] 事实、日期、金额、当事人有没有被改动或"顺手"补充
- [ ] 引用的法条、案例、证据编号与原稿一致
- [ ] 原文的不确定性表述（可能、原则上、通常）是否保留
- [ ] 原文的否定范围与条件限定是否保留
- [ ] 附件、附表、附页是否齐全且编号一致

## 二、校是非（本稿内部）

- [ ] 主体、称谓全文统一
- [ ] 术语前后一致（解除 / 撤销、定金 / 订金、应当 / 可以不被混用）
- [ ] 条件与结论对应：讲了条件的结论不能无条件化
- [ ] 逻辑连贯：结论有依据，依据支撑结论
- [ ] 段落顺序符合该类文书的要求（请求在前、理由在后）
- [ ] 未出现"综上""因此"却无前文铺垫的情况

## 三、红线复核

- [ ] 没有新增事实、主体、时间、金额、因果、请求
- [ ] 没有把主张、证据、推论升级为有权认定
- [ ] 没有改变不确定性、规范强度、否定范围、责任边界
- [ ] 没有以"结构完整"为理由填补缺口
- [ ] 疑似实体法律错误（条号、条文内容、已废止法规）只标"需核验"，未擅自修改

## 四、交付格式

- [ ] 按动作给出了对应交付物（修改稿 / 需确认事项 / 主要修改 / 术语说明 / 结构诊断 / 核对结果）
- [ ] 结构诊断未擅自附带改写稿（除非用户同时要求）
- [ ] 文书链核对未擅自统一改写全部文件（除非用户同时要求）
- [ ] 保留了原有的编号、标题层级与引用格式

## 五、需要提示用户的常见事项

- 需要核验的法条与案例（注明去哪里核）
- 材料缺口（缺什么、向谁要）
- 会影响法律效果的表述分歧（列出两种写法与后果，请用户确认）
- 如果原文来自扫描件或照片，提示回原件复核
