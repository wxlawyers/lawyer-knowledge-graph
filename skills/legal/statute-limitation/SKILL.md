# 诉讼时效与期间计算技能

面向中国民商事诉讼律师的时效与期间分析框架，覆盖诉讼时效全规则与期间计算。

## 适用场景

- 起诉前诉讼时效评估与证据梳理
- 诉讼时效中断、中止情形的认定与证据组织
- 除斥期间（撤销权、解除权、保证期间等）识别
- 法定期间计算（上诉期、举证期、保全异议期等）
- 时效抗辩的应对与反驳

## 执行步骤

### 步骤一：确定时效类型与期间

1. 一般诉讼时效：三年（《民法典》第188条）
2. 最长权利保护期间：二十年（自权利受到损害之日起）
3. 特殊时效：依特别法（如国际货物买卖合同和技术进出口合同争议为四年）
4. 除斥期间：撤销权一年、重大误解撤销权九十日、解除权一年等，不适用中止中断

### 步骤二：时效起算分析

1. 一般起算：自权利人知道或者应当知道权利受到损害以及义务人之日起
2. 分期履行债务：自最后一期履行期限届满之日起算
3. 未成年人遭性侵害损害赔偿：自受害人年满十八周岁之日起算
4. 无/限制民事行为能力人对法定代理人的请求权：自代理终止之日起算

### 步骤三：中断与中止认定

#### 中断（重新计算三年，需有证据）
- 权利人向义务人提出履行请求（催告函、微信催收、对账单）
- 义务人同意履行义务（还款承诺、部分履行）
- 权利人提起诉讼或申请仲裁
- 与提起诉讼或申请仲裁具有同等效力的其他情形

#### 中止（暂停计算，障碍消除后继续）
- 不可抗力
- 无民事行为能力人或者限制民事行为能力人没有法定代理人
- 继承开始后未确定继承人或者遗产管理人
- 权利人被义务人或者其他人控制
- 其他导致权利人不能行使请求权的障碍
- 中止事由须发生在时效期间最后六个月内

### 步骤四：除斥期间与保证期间识别

1. 除斥期间自权利人知道或应当知道权利产生之日起计算，不适用中止、中断、延长
2. 保证期间（约定优先，未约定按主债务履行期届满之日起六个月），期间届满保证责任消灭
3. 撤销权、解除权等形成权过期后丧失，先核对是否已过除斥期间

### 步骤五：期间计算

1. 期间按公历年、月、日、小时计算
2. 期间开始的时和日不计算在内
3. 期间最后一日为法定休假日的，以休假日的次日为最后一日
4. 期间最后一日截止时间为二十四时；有业务时间的，停止业务活动的时间为截止时间

### 步骤六：时效抗辩应对

1. 对方主张时效抗辩时，检索中断/中止证据
2. 核对时效起算点是否有争议（知道或应当知道的时间）
3. 判断是否适用最长二十年的例外
4. 时效抗辩不得主动释明，但应在答辩中有效回应

## 注意事项

- 时效抗辩需由当事人主动提出，法院不得依职权适用
- 中断证据（催收记录）应提前固定，避免起诉时才发现无法举证
- 形成权（撤销权、解除权）过期后无法恢复，涉及此类权利先行预警
- 保证期间与诉讼时效是两套规则，涉及担保案件务必分开分析
