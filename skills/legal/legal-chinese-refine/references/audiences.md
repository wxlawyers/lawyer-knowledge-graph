# 读者与正式度

> 同一件事，写给谁看决定怎么写。改写前先确定读者与关系，再决定用词、句长和详略。

## 五类读者

| 读者 | 表达要求 | 禁忌 |
|------|----------|------|
| **法院 / 仲裁机构** | 准确、克制、就事论事；每项主张有事实与依据支撑 | 情绪化评价、对对方的人身指责、无依据的推测 |
| **当事人（委托人）** | 结论前置、少用术语、解释风险与选择；保留不确定性 | 暴露策略底牌、写内部风险评估原话、把推测说成确定 |
| **对方 / 对方代理人** | 明确主张与立场，留有余地；不用侮辱性表述 | 泄露我方证据弱点、预判我方下一步 |
| **监管机关** | 严格对应问询事项，逐项回应；依据具体到条款 | 答非所问、笼统表态、回避核心问题 |
| **公众（普法 / 传播）** | 通俗、结论明确、标注适用边界 | 把个案结论说成普遍规则、承诺结果 |

## 正式度调节

| 场景 | 用法 |
|------|------|
| 正式文书 | 书面语、完整句式、规范称谓；不用缩略语和网络用语 |
| 内部备忘 | 可简写，但事实与判断仍要分层 |
| 口头表达（庭审发言、当事人沟通） | 短句、少从句；专业术语当场解释；一件事一句话 |

## 称谓与指代

- 同一主体全文只用一种称法（要么全称，要么"原告/被告"，不要混用）；
- 首次出现用全称并标注简称，之后统一用简称；
- 指代明确到具体主体，避免连续使用"其""该方""上述当事人"造成歧义；
- 与主体信息一致：公司名称、法定代表人、住所地要与工商登记或卷宗一致。

## 语气校准

| 不要 | 换成 |
|------|------|
| "对方恶意拖欠，毫无诚意" | "截至 X 日，对方未支付到期款项" |
| "显然""众所周知""不言而喻" | 直接给依据 |
| "必须""一定""毫无疑问" | "应当""可以认定"（除非确实无争议） |
| "希望贵司尽快处理" | "请于 X 日前完成 Y" |
| "综上，原告的诉求毫无依据" | "原告的该项主张缺乏事实与法律依据，理由如下" |
