# 对外交付物模板（脱敏版）

> 配套 `client-communication`。四类交付物：服务计划书、工作通报、决策辅助清单、庭审简报。
> **共同红线**：不暴露策略底牌、不评价法官与对方、不写未核实事实、不把推测写成结论。

---

## 一、服务计划书

**用途**：阶段启动时发给当事人，管理预期、明确分工。

```markdown
# {案件简称} 服务计划书

致：{当事人}
日期：{YYYY-MM-DD}

## 一、本阶段要解决的问题

{用一两句话说明这一阶段的目标，不写策略细节}

## 二、工作安排

| 阶段 | 我们做什么 | 预计时间 | 需要您配合 |
|------|------------|----------|------------|
| 1 | {例如：整理并提交立案材料} | {时间} | {例如：提供身份证明原件} |
| 2 | | | |

## 三、需要您提供的材料

- {材料名称}（{份数/形式要求}）

## 四、费用与结算

{费用构成、支付节点、可能的额外支出（鉴定费、公告费、差旅等）}

## 五、沟通方式与频率

{主要沟通渠道、进展通报频率、紧急情况联系方式}
```

---

## 二、工作通报

**用途**：有实质进展时发出。核心是 **做了什么 → 结果 → 下一步**。

```markdown
# {案件简称} 工作通报（{YYYY-MM-DD}）

## 一、本期完成的工作

- {具体动作，例如：已完成立案材料提交，法院受理并出具受理通知书}

## 二、结果

{客观结果，含时间节点、文号、金额等可核对信息}

## 三、下一步安排

| 事项 | 负责方 | 预计时间 |
|------|--------|----------|
| | | |

## 四、需要您配合的事项

- {具体、可执行，例如：请于 X 日前提供 Y}
```

**避免的写法**：只写"已在跟进""正在处理"——没有信息量，反而让当事人不安。

---

## 三、决策辅助清单

**用途**：需要当事人拿主意时。**决定权归当事人**，律师只做结构化分析。

```markdown
# {案件简称} 决策辅助清单（{事项}）

## 一、需要您决定的问题

{一句话说清要决定什么，例如：是否接受对方的和解方案}

## 二、选项对比

| 对比项 | 方案A：{名称} | 方案B：{名称} |
|--------|----------------|----------------|
| 主要内容 | | |
| 预计结果 | | |
| 时间成本 | | |
| 费用成本 | | |
| 主要风险 | | |
| 不确定性 | | |

## 三、需要提醒您的几点

- {法律上确定的部分}
- {存在不确定性的部分，明确写"取决于……"}

## 四、您的决定

- [ ] 选择方案A
- [ ] 选择方案B
- [ ] 需要进一步了解后再定

当事人签字/确认：__________  日期：__________
```

**注意**：不要替当事人下结论，也不要只给一个方案让人"点头"。给选项、给利弊、给不确定性，决定权交回。

## 四、庭审简报

### 开庭前

```markdown
# {案件简称} 开庭前简报

## 一、开庭信息

| 项目 | 内容 |
|------|------|
| 开庭时间 | |
| 地点 | |

## 二、准备工作情况

{已完成事项，例如：证据已提交并装订、证人已通知}

## 三、需要您注意的事项

- 需要携带的材料：{}
- 着装与到场时间：{}
- 庭审中一般流程说明：{}
- 需要您本人出席的事项：{}
```

### 开庭后

```markdown
# {案件简称} 庭审简报（{YYYY-MM-DD}）

## 一、庭审基本情况

{开庭时长、参与人员、公开进行的程序事项}

## 二、法庭归纳的争议焦点

1. {}

## 三、下一步安排

| 事项 | 期限 | 说明 |
|------|------|------|
| | | |
```

**只写公开发生的庭审情况**：法庭归纳、双方当庭陈述与举证质证情况、当庭确定的事项。**不写**内部策略、对法官或对方的评价、尚未确定的预判。

---

## 五、结案报告（简版）

```markdown
# {案件简称} 结案报告

## 一、案件结果

{终局结果：判决/调解/撤诉，主要条款}

## 二、办理过程回顾

{关键节点时间线}

## 三、费用结算

{已收、已支出、结余或补收}

## 四、后续提示

- 上诉期限：{日期}
- 履行/执行安排：{}
- 材料归档与原件返还：{}
```

---

## 六、发送前自查

| 检查项 | 通过 |
|--------|------|
| 有没有写着写着变成对内材料（出现策略、预判、内部分级）？ | |
| 有没有未核实的事实被写成结论？ | |
| 有没有对法官、对方、对方律师的评价？ | |
| 需要当事人决策的，是否明确写清"由您决定"？ | |
| 金额、日期、案号是否与卷宗一致？ | |
